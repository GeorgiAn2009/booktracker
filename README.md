
Графическое приложение позволяющее конвертировать из одной валюты в другую.

## Автор
[Григорий Анисимов]

## Описание

Приложение позволяет:
* Конвертировать валюты по курсу.
* Показывает историю конвертаций.
* Сохраняет результаты в JSON файл.

## Как использовать

1. Запустите приложение: `python main.py`.
2. Заполните поля валют и нажмите сумма.
